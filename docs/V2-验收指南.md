## 三、推荐验收路线（5 分钟）

1. **首页** → 看情绪指数仪表盘 + 巨鲸动态 + 十大市场温度条
2. **资产市场** → 搜「AI-DEEPSEEK」→ 进详情
3. **详情页** → 切周线 + MACD → 「合约」开 5x 多单 → 回现货挂限价单
4. **我的资产** → 看持仓、合约仓位、挂单
5. **AI 智能** → 运行机会雷达 → 问顾问「市场情绪怎么样」「有什么机会」
6. **WEG 生态** → 金库质押 → 贡献系统领奖

## 四、数据维护速查

- 全部数据在 `src/data/assets.ts`：新增资产 = 板块数组加一行 `['代码','名称','En','简介',发行价,波动率,市值亿,评分,['标签'],'发行方']`
- 指数：`INDEXES` 数组；板块权重：`SECTORS` 的 `weight`
- 巨鲸：`src/data/whales.ts`；顾问意图：`src/ai/advisor.ts`

## 五、部署

GitHub Actions（`.github/workflows/deploy.yml`）已配置：push master → build → Cloudflare Pages（项目 `ai-exchange`）。
需在 GitHub 仓库配置 secrets：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`。
